# Cellix workspace packages

Reusable Cellix packages copied from the CellixJS reference to keep TypeScript, Rolldown, Vitest, local development, and ArchUnit conventions consistent.

Copied for this scaffold:

- `@cellix/config-typescript`
- `@cellix/config-vitest`
- `@cellix/config-rolldown`
- `@cellix/local-dev`
- `@cellix/archunit-tests`

Additional Cellix packages (domain-seedwork, mongoose-seedwork, serenity-framework, and others) can be copied later from `/Volumes/files/src/cellixjs/packages/cellix` when a feature needs them.
